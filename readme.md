# AI Cybersecurity Threat Detection

## Objective
Detect cybersecurity threats using machine learning and packet analysis.

## Technologies Used
Python, Scapy, Streamlit, Scikit-learn, Joblib, Pandas

## Features
- Dataset preprocessing
- ML model training
- Saved model using Joblib
- Packet capture using Scapy
- Live monitoring script
- Streamlit dashboard
- Threat prediction output

## Project Flow
Dataset → Preprocessing → Model Training → Saved Model → Packet Capture → Feature Extraction → Prediction Dashboard

## Future Scope
- Use CICIDS2017 / UNSW-NB15 dataset
- Improve real-time classification accuracy
- Add live dashboard alerts
- Deploy on cloud
